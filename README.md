《本脚本用于应对学习通等禁止Ctrl.C、Ctrl.V的快捷键使用场景，采用脚本类人化的古法输入》
脚本效果：
	1）独立ui界面
	2）可粘贴输入文本框
	3）输入按钮、退出按钮
	4）自动定位识别写入
使用方法：
	1、将脚本下载后通过anaconda配置好环境，主要的软件包：
		pyautogui>=0.9.53
		mouse>=0.7.1
		清华源：pip install pyautogui mouse -i https://pypi.tuna.tsinghua.edu.cn/simple
		阿里源：pip install pyautogui mouse -i https://mirrors.aliyun.com/pypi/simple/
		同样的套路，下载其他包的时候换包名就行
	2、运行后会弹出ui界面，分布为：
		上部分：			输入框
		下部分：写入按钮 退出按钮
	3、将需要写入的代码粘贴进输入框
		注意！：由于python脚本对中文不太友好，所以当写入到中文时会报错退出，所以代码粘贴前需要去除或者替换全部中文
	4、粘贴完成后点击ui界面左下角的写入按钮（建议先打开网页版的学习通后再点击ui界面进行操作，并将键盘输入格式从“拼音”换为“ENG”），然后再用鼠标点击需要写入的位置，在3s后会自动进行写入操作
		ps：首先将输入法换为“ENG”是因为如果是拼音输入不管是英文还是中文都会切换为中文，然后写入风格就是拼音，出现乱码，然后先打开网页版学习通是因为鼠标的输入定位只会出现在一个地方，我们需要让脚本知道要在哪里进行写入
	5、写入过程中最好对电脑别进行页面切换和鼠标点击，不然会识别错误导致写入进别的地方（比如微信文件传输助手的聊天），写入完成后会弹出提示框，点掉提示框后直接退出脚本就行
	6、脚本写完之后最好进行一遍格式和内容核对，多少看看，因为比如python就是很讲究缩进，如果格式乱了会导致运行错误
