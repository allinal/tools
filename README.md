# Stable Format Typer

本脚本旨在应对学习通等在线平台禁止使用 Ctrl+C/Ctrl+V 快捷键的场景，采用模拟人工逐字符输入的“古法”方式，确保文本格式（包括空行、前导空格/Tab 和行尾空格）能够被准确还原。

## 功能特点

- **独立 UI 界面**：基于 Tkinter 构建的图形化操作窗口。
- **可视化输入**：提供文本粘贴区域，方便预览待输入内容。
- **自动定位写入**：通过鼠标点击自动识别目标输入位置，无需手动配置坐标。
- **格式保持**：逐字符模拟键盘输入，最大程度保留原文排版结构。

## 环境配置

在使用本脚本前，请确保已安装 Anaconda 或 Python 环境，并安装以下依赖包：

- `pyautogui >= 0.9.53`
- `mouse >= 0.7.1`

### 快速安装

推荐使用国内镜像源以加快下载速度：

**使用清华源：**
```bash
pip install pyautogui mouse -i https://pypi.tuna.tsinghua.edu.cn/simple
```

**使用阿里源：**
```bash
pip install pyautogui mouse -i https://mirrors.aliyun.com/pypi/simple/
```

## 使用方法

1. **启动程序**：运行脚本后，将弹出包含输入框、写入按钮和退出按钮的 UI 界面。
2. **准备内容**：将需要输入的文本粘贴至 UI 界面的输入框中。
   - **注意**：由于底层输入机制限制，建议在输入前去除或替换所有中文字符，否则可能导致脚本报错退出。
3. **设置输入法**：在点击写入前，请务必将系统输入法切换为 **ENG（英文模式）**。若处于拼音输入法状态，无论是中文还是英文字符均可能被识别为拼音候选项，导致输出乱码。
4. **定位目标**：
   - 建议先打开目标网页（如学习通作答页面）。
   - 点击 UI 界面左下角的 **“写入”** 按钮。
   - 移动鼠标至目标输入框位置并单击左键。
5. **自动写入**：脚本将在 3 秒倒计时后开始逐字符输入。在此期间，请勿切换页面或进行其他鼠标/键盘操作，以免焦点偏移导致内容写入错误位置（如微信聊天窗口等）。
6. **完成与核对**：写入完成后会弹出提示框，确认无误后可关闭脚本。由于不同编辑器对缩进的处理逻辑不同，建议写入后人工核对代码格式（特别是 Python 等对缩进敏感的语言），确保没有因自动补全或格式化导致的运行错误。

## 注意事项

- 本脚本仅适用于 Windows 操作系统。
- 建议在目标编辑器中关闭自动补全、自动换行和自动格式化功能，以获得最佳输入效果。
- 脚本通过模拟物理键盘事件实现输入，效率低于剪贴板粘贴，请耐心等待写入完成。
